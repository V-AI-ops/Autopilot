## Автопилот дрона (Эмулятор)

Проект представляет собой программный эмулятор автопилота дрона с консольным управлением, разработанный на Python.

## Инструкция по запуску

1. Требования: Установленный Python 3.10 или выше.
2. Сторонние библиотеки не требуются (использована только стандартная библиотека Python).
3. Запуск программы:
```bash
git clone https://github.com/V-AI-ops/Autopilot.git
cd Autopilot
python main.py
```

## Архитектура проекта 

Код разделен на независимые модули для соблюдения принципа единственной ответственности (SRP):

models.py — структуры данных и перечисления (RCCommand, Target, FCState, AutopilotMode).

exceptions.py — пользовательские исключения (например, FCConnectionError).

config.py — конфигурация (разрешение кадра, лимиты RC, таймауты).

flight_controller.py — потокобезопасный программный эмулятор полётного контроллера.

autopilot.py — ядро автопилота. Управляет FSM, проверяет таймауты и рассчитывает управление.

cli.py — парсер консольных команд и форматированный вывод состояния.

main.py — точка входа, инициализация объектов и graceful shutdown.

## Многопоточность и синхронизация
Программа использует два независимых потока:

Главный поток (CLI Thread) — отвечает за блокирующий ввод input() и вывод информации в консоль.

Фоновый поток (Autopilot Thread) — работает с частотой 20 Гц (цикл каждые 0.05 сек), вычисляет команды и отслеживает потерю сигнала.

Синхронизация данных:
Общие данные (состояние полётного контроллера и текущая цель автопилота) защищены с помощью threading.Lock.
Доступ к критическим секциям осуществляется через контекстный менеджер with self._lock:.
Для предотвращения состояния гонки (Race Condition) при передаче RC-команд используется паттерн защитного копирования (Defensive Copying) — метод get_rc() возвращает новый объект, а не ссылку на внутреннее состояние.

## Управление и расчёт RC-команд
Формирование RC-команд построено на базе пропорционального регулятора с мёртвой зоной (Deadzone).

Вычисление ошибки (смещения):
Определяется разница между координатами цели и центром виртуального кадра (320x240).
DX = X_target - 320, DY = Y_target - 240

Мёртвая зона (Deadzone = 15px):
Если цель находится в пределах мёртвой зоны (abs(DX) <= 15), значение канала устанавливается в нейтральное (1500). Это исключает дрожание дрона при нахождении цели близко к центру.

Пропорциональное управление:
Если цель за пределами мёртвой зоны, применяется формула:
RC = 1500 + (Kp * дельта)

Ограничение (Clamp):
Полученное значение принудительно ограничивается безопасным диапазоном [1000, 2000].

Настраиваемые коэффициенты:
Коэффициенты Kp для Roll и Pitch можно динамически изменять через консоль (команда coef <kp_roll> <kp_pitch>).

## Обработка ошибок и таймауты
Потеря цели: Если координаты цели не обновлялись более TARGET_TIMEOUT (2 секунды), цель считается потерянной. Автопилот не использует устаревшие данные и автоматически переходит из состояния ACTIVE в SEARCH.

Потеря связи с FC: Если Flight Controller отключён (команда fc disconnect),  поток автопилота переводит систему в режим FAILSAFE.

Поведение в FAILSAFE: При аварии автопилот сбрасывает газ (Throttle: 1000) и устанавливает остальные каналы в нейтраль (1500), ожидая восстановления соединения.
